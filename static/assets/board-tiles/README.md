# Generated board tiles

These raster assets form the first graphical Robo Rally board skin. They were
created with OpenAI image generation in one cohesive, orthographic industrial
factory style, then reduced to 256 × 256 for the web. The wall was generated
against a flat green background and converted to a transparent PNG.

The shared prompt contract was: a square, strict top-down orthographic,
high-end painted board-game tile on a quiet, full-bleed dark gunmetal floor.
Every game feature uses one thick, high-contrast silhouette that occupies
roughly 75–90% of the tile and remains recognizable at 32 pixels. The prompts
explicitly prohibit inset panels, perimeter frames, corner brackets, repeated
sub-panels, thin lines, and decorative micro-detail, as well as text, logos,
watermarks, perspective, people, and robots. Each derivative asked for exactly
one floor, pit, repair site, Option repair site, clockwise gear, standard
conveyor, express conveyor, standard conveyor turn, express conveyor turn,
pusher, laser, docking pad, or wall. Directional art is authored facing north
and rotated by the renderer; counterclockwise and left-turn art is mirrored
from its generated counterpart.

repository.
